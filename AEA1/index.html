Para empezar a debatir

¿Usas “internet” y “la web” como si fueran lo mismo?

Piensa en lo que has hecho hoy con el móvil: ¿has leído información, has creado algo, has enviado datos o has usado una app instalada? En esta AEA vamos a separar esos conceptos y a descubrir qué ocurre entre tu dispositivo y el servidor cada vez que utilizas una herramienta digital.

Pregunta para el grupo: ¿Google Docs es una web, una aplicación web, una app móvil o puede ser varias cosas a la vez? Defiende tu respuesta.
