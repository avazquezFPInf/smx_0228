Sesión 1 · Introducción

¿Qué ocurre cuando abres una web?

Internet conecta dispositivos. La web es uno de los servicios que usamos sobre esa red; las aplicaciones web convierten el navegador en una herramienta para trabajar.

Idea clave

Internet no es “una nube”: es una red de redes

Tu móvil, tableta u ordenador actúa como cliente. Cuando escribes una dirección o pulsas un enlace, el cliente envía una petición. Esta viaja por internet hasta un servidor: un ordenador preparado para guardar información y responder a muchas personas. El servidor devuelve una respuesta, por ejemplo una página, una imagen o los datos de tu cuenta.

💻 Cliente
navegador de móvil u ordenador
Petición →
← Respuesta
🗄️ Servidor
guarda, procesa y responde

Ejemplo: al abrir Google Docs, tu navegador pide el documento; el servidor comprueba tus permisos, envía el contenido y guarda los cambios que haces.

El recorrido

De una dirección a una página en pantalla

  1. Escribes una URL, por ejemplo www.ejemplo.com, o pulsas un enlace.
  2. El navegador consulta el DNS, una especie de agenda que traduce ese nombre a la dirección del servidor.
  3. El navegador envía una petición mediante HTTP o HTTPS. HTTPS protege el intercambio de información.
  4. El servidor localiza la información, ejecuta la lógica necesaria y devuelve una respuesta.
  5. El navegador interpreta HTML, CSS y JavaScript y dibuja el resultado que ves y con el que interactúas.

Idea para comprobarlo: abre una web sencilla y observa su URL; después inicia sesión en una aplicación web. ¿En cuál de las dos se intercambian datos personales, permisos o cambios que deban guardarse?

Comparación

Web, aplicación web y aplicación móvil

🌐 Sitio web

Objetivo: informar, mostrar o publicar.

Normalmente lees, miras y navegas. Puede tener formularios sencillos.

Ejemplos: blog, portfolio, web de un centro.

💻 Aplicación web

Objetivo: hacer una tarea.

Creas, editas, guardas, compartes o gestionas datos desde el navegador.

Ejemplos: Google Docs, Classroom, Trello, banca online.

📱 Aplicación móvil

Objetivo: hacer una tarea desde el móvil.

Se instala desde una tienda y está creada para un sistema como Android o iOS.

Ejemplos: WhatsApp, Spotify, cámara.

Importante: no son cajas cerradas. Una tienda puede ser una web informativa y, a la vez, incluir una aplicación web para el carrito, el pago y el área personal. También hay aplicaciones web que se pueden instalar como PWA.

Pista para decidir

La pregunta no es “¿tiene botones?”

Una web puede tener menús, vídeos o un formulario de contacto y seguir teniendo como objetivo principal informar. Lo que suele convertirla en aplicación web es que el usuario realiza una tarea y el sistema procesa, guarda o personaliza datos: redactar un documento, pedir una cita, organizar tareas, consultar notas o hacer una compra.

Regla rápida: si al salir no importa quién eres ni qué has hecho, probablemente estás ante una web informativa. Si debes iniciar sesión o recuperar tu trabajo después, hay funciones de aplicación web.

Reto individual

Clasificad sin abrir Google

Decide si cada caso es principalmente un sitio web, una aplicación web, una aplicación móvil o una mezcla. Debéis justificar la decisión usando las palabras informar, tarea, datos, navegador e instalar.

  1. La web del instituto con sus estudios y datos de contacto.
  2. Un documento que tres personas editan al mismo tiempo en Google Docs.
  3. La app de Spotify instalada en un teléfono.
  4. Una tienda online: catálogo, cesta, pago y cuenta de cliente.

Puesta en común: Comparte con tus compañeros las decisiones que has tomado.
