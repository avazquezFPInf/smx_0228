Qué es Nextcloud

Un Drive propio

Nextcloud es una plataforma de almacenamiento y colaboración que instalamos y administramos nosotros. Ofrece funciones parecidas a Drive o Dropbox —archivos, carpetas, usuarios, permisos, versiones y enlaces—, pero no depende de una cuenta de Google o Dropbox.

Para funcionar necesita un servidor web, PHP, una base de datos y espacio de almacenamiento. En esta práctica cada alumno tendrá su propia instalación en Ubuntu, ya sea en una máquina física o en una máquina virtual.

Importante: Nextcloud sirve para gestionar archivos y colaborar de forma privada. No será el lugar donde publiquemos la web HTML del evento: eso se hará en Pt2.3 con Dotació.cat.

Paso 1

Prepara Ubuntu y el servidor

Trabaja en tu instalación individual de Ubuntu. Puede ser una máquina virtual o una instalación física, pero todo el trabajo debe quedar en tu propia máquina.

  1. Actualiza los paquetes del sistema.
  2. Instala Apache, MariaDB, PHP y los módulos necesarios para Nextcloud.
  3. Activa los servicios y comprueba que Apache responde al abrir http://localhost.
Terminal
sudo apt update
sudo apt install apache2 mariadb-server libapache2-mod-php php-mysql php-gd php-curl php-zip php-xml php-mbstring php-intl php-bcmath unzip wget -y
sudo systemctl enable --now apache2 mariadb

Evidencias: captura de http://localhost y explicación de qué función cumple Apache, PHP y MariaDB.

Paso 2

Crea la base de datos e instala Nextcloud

  1. Crea una base de datos llamada nextcloud y un usuario exclusivo para ella.
  2. Descarga Nextcloud, descomprímelo en /var/www/ y asigna la propiedad al usuario www-data.
  3. Activa los módulos de Apache necesarios y reinicia el servicio.
  4. Abre http://localhost/nextcloud y completa el asistente de instalación.
  5. Crea el usuario administrador. Usa una contraseña segura, pero no la escribas ni la muestres en las capturas.
Terminal
sudo mysql
CREATE DATABASE nextcloud CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'ncadmin'@'localhost' IDENTIFIED BY 'TU_CONTRASENA_SEGURA';
GRANT ALL PRIVILEGES ON nextcloud.* TO 'ncadmin'@'localhost';
FLUSH PRIVILEGES;
EXIT;

cd /tmp
wget https://download.nextcloud.com/server/releases/latest.zip
unzip latest.zip
sudo mv nextcloud /var/www/
sudo chown -R www-data:www-data /var/www/nextcloud
sudo a2enmod rewrite headers env dir mime
sudo systemctl restart apache2

Evidencias: captura de la pantalla principal de Nextcloud y resumen de qué datos se han configurado durante la instalación.

Paso 3

Crea el equipo del evento

Desde la administración de Nextcloud crea los grupos Organización y Comunicación. Crea, como mínimo, los usuarios de prueba organizacion, comunicacion e invitado. No reutilices tu contraseña personal para estas cuentas.

Explica en el documento de evidencias la diferencia entre usuario, grupo y permiso.

Evidencias: captura de los grupos y usuarios creados, y tabla que relacione cada usuario con su grupo y función dentro del evento.

Paso 4

Organiza las carpetas y asigna permisos

Con el usuario administrador crea la carpeta Evento y dentro las siguientes subcarpetas:

  • Cartelería: Comunicación puede editar; Organización solo puede consultar.
  • Programa: ambos grupos pueden editar.
  • Documentación interna: Organización puede editar; Comunicación solo puede consultar.
  • Inscripciones: solo Organización puede editar y consultar.

Comparte cada carpeta con los grupos correspondientes. Después abre una ventana privada e inicia sesión con los usuarios de prueba para comprobar los permisos.

Evidencias: árbol de carpetas, configuración de una carpeta compartida, una prueba de acceso permitido y una prueba de acceso denegado.

Paso 5

Versiones y enlaces seguros

  1. Entra como comunicacion, crea un archivo de texto o sube un cartel a Cartelería y haz tres cambios visibles.
  2. Consulta el historial de versiones y restaura una versión anterior.
  3. Genera un enlace público para compartir el archivo o una carpeta.
  4. Configura contraseña y fecha de caducidad en el enlace.
  5. Comprueba el enlace desde una ventana privada.

Evidencias: historial de versiones, enlace configurado sin mostrar su contraseña y comprobación desde una ventana privada. Explica para qué sirve cada medida de seguridad.

Paso 6

Sincroniza y organiza una tarea del evento

  1. Instala el cliente de escritorio de Nextcloud en Ubuntu: sudo apt install nextcloud-desktop -y.
  2. Configura el cliente para sincronizar únicamente la carpeta Evento, no todo el contenido.
  3. Crea o activa una herramienta de trabajo de Nextcloud, como Tareas o Calendario.
  4. Añade tres tareas o eventos relacionados con tu evento: preparar cartel, revisar programa y publicar información.

Evidencias: carpeta local sincronizada, archivo visible tanto localmente como en Nextcloud web y lista de tareas o calendario. Explica qué ventaja tiene sincronizar solo una carpeta concreta.

Entrega

Comprobación final

  • Nextcloud funciona en http://localhost/nextcloud.
  • Existen usuarios, grupos y carpetas del evento.
  • Has probado al menos un permiso permitido y uno denegado.
  • Has recuperado una versión anterior y creado un enlace protegido.
  • Has configurado la sincronización de una carpeta concreta.
  • El documento de evidencias contiene explicaciones además de capturas.

Conclusión: explica en 6 a 8 líneas qué diferencia hay entre Drive, Dropbox, Nextcloud y el alojamiento web donde se publicará la web del evento.
