Pt2.2 · Nextcloud

01 Instalación

Prepara Ubuntu y monta el servicio que utilizará Nextcloud.

Antes de instalar

Qué vamos a montar

En esta parte prepararemos los cuatro elementos que hacen funcionar Nextcloud. Apache recibe las peticiones del navegador; PHP ejecuta Nextcloud; MariaDB almacena los datos de la aplicación; y la carpeta de datos conserva los archivos.

1. Ubuntu2. Apache y PHP3. MariaDB4. Nextcloud
Paso 1

Prepara Ubuntu y los servicios

Ahora vas a hacer: instalar el servidor web, la base de datos y las extensiones de PHP que necesita Nextcloud. Al terminar comprobarás que Apache responde en el navegador.

  1. Actualiza los paquetes del sistema.
  2. Instala Apache, MariaDB, PHP y los módulos necesarios.
  3. Activa los servicios y abre http://localhost.
Terminal
sudo apt update
sudo apt install apache2 mariadb-server libapache2-mod-php php-mysql php-gd php-curl php-zip php-xml php-mbstring php-intl php-bcmath unzip wget -y
sudo systemctl enable --now apache2 mariadb

Paso 2

Crea la base de datos e instala Nextcloud

Ahora vas a hacer: crear una base de datos vacía y un usuario exclusivo para Nextcloud, colocar la aplicación en el servidor y preparar Apache para que pueda aplicar sus reglas de acceso.

Lo creas tú

Una base de datos vacía llamada nextcloud y el usuario ncadmin, con permiso para usar solo esa base de datos.

Lo crea Nextcloud

Sus propias tablas y su estructura interna, automáticamente al terminar el asistente. No debes escribir ningún comando CREATE TABLE.

  1. Crea la base de datos vacía nextcloud y el usuario ncadmin. No crees tablas manualmente.
  2. Descarga Nextcloud, colócalo en /var/www/html y prepara la carpeta de datos.
  3. Activa la configuración y los módulos de Apache.
  4. Abre http://localhost/nextcloud y completa el asistente.
Terminal · base de datos
sudo mysql
-- Solo creamos una base vacía y un usuario. Nextcloud creará sus tablas.
CREATE DATABASE nextcloud CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
CREATE USER 'ncadmin'@'localhost' IDENTIFIED BY 'TU_CONTRASENA_SEGURA';
GRANT ALL PRIVILEGES ON nextcloud.* TO 'ncadmin'@'localhost';
FLUSH PRIVILEGES;
EXIT;
Terminal · archivos y Apache
cd /tmp
wget https://download.nextcloud.com/server/releases/latest.zip
unzip latest.zip
sudo mv nextcloud /var/www/html/
sudo chown -R www-data:www-data /var/www/html/nextcloud
sudo install -d -o www-data -g www-data /var/ncdata
sudo tee /etc/apache2/conf-available/nextcloud.conf >/dev/null <<'EOF'
<Directory /var/www/html/nextcloud/>
  Require all granted
  AllowOverride All
  Options FollowSymLinks MultiViews
</Directory>
EOF
sudo a2enmod rewrite headers env dir mime
sudo a2enconf nextcloud
sudo systemctl restart apache2

En el asistente selecciona /var/ncdata como carpeta de datos. Indica la base nextcloud y el usuario ncadmin. No muestres contraseñas en ninguna captura. Al pulsar instalar, Nextcloud crea automáticamente sus tablas: esa tarea pertenece a la aplicación, no a ti.
